# Changelog

This project uses an unreleased capability log until a deployment is actually tagged. Dates refer to implementation records, not public service availability.

## Unreleased — 2026-10-19

### Added

- Merchant inventory with codes, LYD-default currency selection, availability, product images and code-driven answers.
- Configurable business responses and connected-channel delivery adapters.
- Selected-video TikTok public-comment workflow with explicit access/coverage limits.
- Arabic/English administration, local Cairo, responsive top navigation and the Reply identity library.
- Persistent light/dark themes and an organic transition shared by theme and locale changes.
- Customer service runtime with email OTP, isolated SQLite workspaces, trial quotas and one account per platform.
- Docker/Caddy pilot configuration, backup tooling, English handbook and repository CI.

### Refined

- Dark primary writing is white with pale supporting text and distinct surfaces.
- Top identity uses the standalone R symbol; anonymous root opens sign-in, with signup available beside it.
- Language switching preserves eligible ordinary field/menu state without persisting sensitive code/secret fields.

### Explicitly deferred

- eZone checkout, payment settlement and customer-facing paid activation.
- Production platform approval, public launch and capacity claims.
- PostgreSQL, object storage and durable distributed job infrastructure.

### Heritage

The original single-shop Cloudflare starter remains in the preserved upstream history and can run separately. Its archived setup guide is under `docs/LEGACY-CLOUDFLARE.md`.
