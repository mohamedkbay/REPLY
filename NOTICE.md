# Attribution and asset provenance

## Upstream software

Reply is derived from [paulmil11/manychat-lite-cloudflare](https://github.com/paulmil11/manychat-lite-cloudflare). Its original Git history is preserved, and the MIT license/copyright notice for Paul Millerd remains in `LICENSE`. Reply-specific development adds merchant inventory, product media replies, channel adapters, TikTok comment handling, bilingual presentation, identity assets and the Node customer service pilot.

The repository is not affiliated with ManyChat, Meta, TikTok, Telegram, Resend or Afternow. Provider names describe interoperability. External provider terms and account permissions remain separate from this repository's software license.

## Typography

Cairo font files and their bundled SIL Open Font License are included in `public/fonts/cairo/OFL.txt` and `assets/brand/fonts/OFL.txt`. Preserve those licenses when redistributing the fonts. The exported Reply wordmark is vector outline artwork, not interface text rendered from a remote font service.

## Reply identity

The R monogram, wordmark variants, patterns, interface icons, application/social formats and motion artwork were authored for this project and supplied as editable source exports. `assets/brand` contains the larger library; `public/brand` contains the application subset. No new raster illustration was generated for the dark-mode or compact-logo refinements. Screenshots are captures of the local implementation and include labelled demonstration inventory where shown.
